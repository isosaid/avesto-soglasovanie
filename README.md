# Мувофиқасозии дархостҳо

Платформа согласования заявок на оплату (дархост) по импортным контрактам холдинга **ҶДММ «Авесто Гуруҳ»**.

Интерфейс — на русском, печатные формы документов — на таджикском.
Сайт статический (GitHub Pages), база — таблица Google Sheets через веб-приложение Apps Script.

## Что умеет

- **Дархостҳо** — заявки на оплату: позиции, суммы в валюте и эквивалент в сомони по курсу, привязка к контракту.
- **Маршрут согласования** — пять виз. Порядок свободный: четверо подписывают когда угодно, кто раньше дошёл, как с бумажным бланком. Ген. директор холдинга утверждает последним — его кнопка появляется, только когда остальные четверо уже подписали.

  | № | Должность | Подписант |
  |---|---|---|
  | 1 | Муовини директори генералӣ оид ба самти паррандапарварӣ | Ҳакимов З. |
  | 2 | Муовини директори генералӣ оиди молия | Ибодов Д.М. |
  | 3 | Сармуҳосиби ҶДММ «Мармарӣ» | Зоиров С.А. |
  | 4 | Директори генералии ҶДММ «Мармарӣ» | Турсунов А.Г. |
  | 5 | Директори генералӣ ҶДММ «Авесто Гуруҳ» — утверждение | Муҳамад Мирзо |

  Порядок повторяет бумажный бланк, который визируется снизу вверх: подписи на бланке идут от ген. директора холдинга вниз, а собираются в обратную сторону — начиная с зама по птицеводству.

  Каждый подписывает только за себя и только со своим PIN-кодом; дважды подписать нельзя. Отказ требует причины и останавливает маршрут. Проверки продублированы на сервере — обойти их, правя страницу в браузере, не получится.
- **Шартномаҳо** — реестр контрактов: сумма инвойса, график платежей, остаток к оплате, ГТД.
- **Бланк дархоста** — печатная форма на таджикском, один в один с исходным Excel, включая сумму прописью («як миллиону шашсаду шасту ҳафт ҳазор евро»). Печать и сохранение в PDF — через печать браузера.
- После прохождения маршрута оплата отмечается в заявке и уменьшает остаток по контракту.

## Импорт реестра из Excel

Кнопка **«Импорт Excel»** в шапке загружает реестр прямо из файла — того самого, который ведёт финансовый отдел («Мархилаи-2 — ЗАЯВКИ на выделение ДС»). Колонки ищутся по названиям, а не по буквам, поэтому читаются обе версии файла: и та, где под шапкой два ряда подзаголовков, и та, где строки идут сразу.

Что берётся из файла: поставщик, страна, номер и дата контракта, объект, продукция, валюта, сумма инвойса, курс заявки и **фактические** оплаты из группы «Фактическая Оплата» — с датами и суммами. Плановые транши «К оплате 1/2/3» не импортируются: это график, а не проведённые платежи.

Эквивалент в сомони считается по курсу выделения (последний «Курс» в шапке), а не по курсу заявки — иначе итог расходится с реестром на десятки тысяч сомони.

Перед загрузкой показывается предпросмотр: сколько контрактов и платежей распознано, суммы по валютам и предупреждение о переплатах. Можно заменить реестр целиком или дополнить существующий по номеру контракта.

## Три режима работы

| Что заполнено в `config.js` | Как работает |
|---|---|
| ничего | Данные живут в этом браузере. Пополнять — кнопкой «Импорт Excel» |
| `SHEET_ID` | Реестр читается прямо из таблицы Google Sheets. Всё видно, визы ставить нельзя |
| `API_URL` | Полный режим: чтение и запись, визы и платежи идут в таблицу |

Для режима `SHEET_ID` таблицу нужно открыть на чтение по ссылке: «Настройки доступа» → «Все, у кого есть ссылка» → «Читатель». Имейте в виду: после этого реестр сможет открыть любой, кто знает ссылку на сайт, — права Google на запись при этом не выдаются.

## Установка

### 1. Таблица-база

Создайте новую таблицу Google Sheets — она будет базой данных.

### 2. Серверная часть

1. В таблице: **Расширения → Apps Script**.
2. Удалите содержимое `Код.gs` и вставьте весь файл [`apps-script/Code.gs`](apps-script/Code.gs).
3. Сохраните, выберите функцию `setup` и нажмите **Выполнить**. Разрешите доступ, когда Google спросит.
   Скрипт создаст шесть листов и заполнит справочник подписантов.
4. Откройте лист **Имзокунандагон** и впишите каждому подписанту PIN в колонку `pin`.
   Без PIN визировать нельзя. PIN наружу не отдаётся — сайт получает только признак, что он задан.
5. **Развернуть → Новое развёртывание → Веб-приложение**:
   - «Запуск от имени» — **От моего имени**;
   - «У кого есть доступ» — **У всех**.

   Скопируйте выданный адрес вида `https://script.google.com/macros/s/AKfycb.../exec`.

### 3. Сайт

Впишите этот адрес в [`assets/config.js`](assets/config.js):

```js
window.AVESTO_CONFIG = {
  API_URL: "https://script.google.com/macros/s/AKfycb.../exec",
  ...
};
```

Закоммитьте — GitHub Pages обновится за минуту.

Пока `API_URL` пуст, сайт работает автономно: данные лежат только в браузере и другим подписантам не видны. Об этом на странице висит предупреждение.

> При каждом изменении `Code.gs` создавайте **новое** развёртывание (или обновляйте существующее с новой версией), иначе сайт продолжит обращаться к старому коду.

## Структура таблицы

| Лист | Что хранит |
|---|---|
| `Шартномаҳо` | контракты: номер, дата, поставщик, страна, объект, продукция, валюта, курс, банк, сумма инвойса, ГТД, файл |
| `Пардохтҳо` | платежи по контрактам: сумма, дата, курс, эквивалент в сомони, основание |
| `Дархостҳо` | заявки: номер, дата, предприятие, контракт, валюта, курс, обоснование, отметки об отправке и оплате |
| `Сатрҳо` | позиции заявок |
| `Имзоҳо` | визы: заявка, должность, решение, время, комментарий |
| `Имзокунандагон` | справочник подписантов: должность, ФИО, PIN, порядок в маршруте |

Состав подписантов задаётся листом `Имзокунандагон` — чтобы добавить, убрать или переименовать подписанта, правьте таблицу, а не код. Колонка `order` задаёт порядок отображения; последний по `order` считается утверждающим и подписывает только после всех остальных.

## Про безопасность

Веб-приложение открыто по адресу всем, у кого есть ссылка, — так работает статический сайт без сервера. Защита виз держится на PIN-кодах из таблицы: подписать за другого, не зная его PIN, нельзя. Читать данные может любой, кто знает адрес сайта. Если понадобится закрыть и чтение, базу нужно переносить на Supabase со входом по логину.
